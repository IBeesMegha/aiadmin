📋 Checklist

  • Widget server (localhost:3000) is running
  • Widget is enabled in admin panel
  • Chat bubble visible in bottom corner
  • Can click to open chat panel
  • Can type and send messages
  • Receive AI responses

🛠️ Troubleshooting

If widget doesn't appear:

  1. Open browser DevTools (F12)
  2. Check Console tab for errors
  3. Check Network tab for failed requests
  4. Verify localhost:3000 is accessible
  5. Ensure widget is enabled in admin panel
